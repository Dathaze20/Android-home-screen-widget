## Taking them

Power + Volume Down together. They land in **Gallery → Screenshots**.

Screenshots 3 and 4 are the pair that proves the whole idea, so take them back to back without
changing anything in between.

## Before you upload

- **Check what is in your notification bar and on your home screen.** Message previews, contact
  names, email addresses and app badges all end up in a public repository permanently. Turning on
  Do Not Disturb first gives a clean status bar.
- **Think about the photos themselves.** Family pictures on a public README are a choice, not an
  accident to discover later. Swapping in a few neutral pictures for the screenshots, then putting
  your own back, is a reasonable thing to do.

## Uploading

Easiest route, from the phone:

1. Go to **[the `docs/screenshots` folder](https://github.com/Dathaze20/Android-home-screen-widget/tree/main/docs/screenshots)**.
2. **Add file → Upload files.**
3. Pick all four. **Rename each to the exact file name in the table above** — the README links to
   those names and nothing else.
4. Commit.

PNG is preferred. If a file is over about 2 MB, let the upload convert it or shrink it first; a
repository is a poor place for 8 MB screenshots.

Once all four are in, the images in the README appear by themselves. Delete this file's
placeholder note at the top when they do.
